# Included extended superfamily-alignment data

These files are the verified inputs and outputs used to construct the 550-sequence extended alignment and prepare the superfamily motif/logo mappings.

| Folder | Contents |
|---|---|
| `representatives/` | The 550 selected accessions and their unaligned sequences |
| `alignments/` | Initial L-INS-i, manually trimmed 7TM, ClipKIT, guide-tree, refined G-INS-i, and selected family-reference alignments |
| `model_selection/` | IQ-TREE2 report for the preliminary guide-tree alignment |
| `trees/` | Preliminary RAxML-NG guide trees and execution log |
| `logo_outputs/` | Automatically ranked and manually curated family-reference tables |

Original analysis filenames are retained for provenance, but the README describes files by their analytical role rather than by run date.
