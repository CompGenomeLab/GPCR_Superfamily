# Included primary phylogeny data

These files are the verified outputs used for the primary 455-sequence phylogeny.

| Folder | Contents |
|---|---|
| `representatives/` | The 455 selected accessions and their unaligned sequences |
| `alignments/` | Initial L-INS-i, manually trimmed 7TM, ClipKIT, guide-tree reordered, G-INS-i, and final ClipKIT alignments |
| `model_selection/` | IQ-TREE2 reports showing `JTT+FO+R8` for the preliminary and final alignments |
| `trees/` | Preliminary and final RAxML-NG searches, 500 bootstraps, TBE support, MRE consensus, and annotated figure tree |
| `visualization/` | SVG rendering of the final alignment used in the manuscript figure |

The long filenames are retained intentionally so every artifact can be matched directly to the original HPC output and execution logs.
